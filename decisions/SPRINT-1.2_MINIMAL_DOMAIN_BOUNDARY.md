# Sprint 1.2 — Minimal domain boundary

**Status:** APPROVED IMPLEMENTATION SCOPE
**Approved by:** Product Owner, 2026-09-30

Sprint 1.2 authorizes only opaque stable identifier types for conceptual domain identities.
Their string values have no format, generation, validation, ordering, ownership, storage, or
network semantics in this sprint.

No domain entity, enum, default value, use-case input/output contract, score, configuration,
account schema, friend-code rule, rival selection, date authority, or derived metric is approved
by this record. All related `TECH-PENDING-*` and `DATA-PENDING-*` decisions remain pending.
